# AI agent instructions

This repository is owned by scottcl88. AI coding assistants working here must:

- Never commit secrets, API keys, credentials, connection strings, or personal data (PII). Use environment variables or a secret manager; keep examples as placeholders.
- Work on a branch and open a pull request; do not push directly to the default branch or force-push.
- Keep changes minimal and in scope; do not weaken tests, linting, or security settings.
- Do not add or change the license, copyright notices, or security policy without explicit owner approval.
- Do not add third-party code or dependencies without noting their license and provenance.
- Run the project's build and tests before proposing changes, and state what was and was not verified.
- Disclose AI assistance in PR descriptions.
- Report security issues privately as described in SECURITY.md.
