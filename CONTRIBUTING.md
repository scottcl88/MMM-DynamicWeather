# Contributing

Thanks for your interest in this project.

By contributing you agree your contributions are licensed under the repository's MIT license.

## Guidelines

- Open an issue to discuss significant changes first.
- Use a branch and open a pull request; keep changes small and focused.
- Never commit secrets, credentials or personal data.
- Make sure the build and tests pass, and describe how you verified your change.
- Disclose any AI assistance in your pull request description.
- Report security problems privately; see [SECURITY.md](SECURITY.md).
- Be kind; see the [Code of Conduct](CODE_OF_CONDUCT.md).
