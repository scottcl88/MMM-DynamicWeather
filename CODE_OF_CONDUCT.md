# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our standard

Be respectful and constructive. Harassment, discrimination, personal attacks, doxxing (publishing others' private information), and other unprofessional conduct are not acceptable in issues, pull requests, discussions or any project space.

## Enforcement

The maintainer may remove, edit or reject comments, commits, issues and other contributions that violate this code, and may temporarily or permanently ban contributors. Report concerns privately via the repository's Security tab (*Report a vulnerability*) or by contacting the maintainer, @scottcl88, through GitHub.

The full Contributor Covenant text applies to the extent not summarized here.
